PINK BIRTHDAY WEBSITE
=====================

1. Buka index.html dalam browser.
2. Folder assets wajib kekal bersama index.html.
3. Letakkan gambar sendiri dengan nama:
   photo1.jpg
   photo2.jpg
   photo3.jpg
   photo4.jpg
   final.jpg
4. Edit teks/password dalam bahagian CONFIG di script.js.

PASSWORD DEFAULT: birthday

Ciri:
- Opening envelope animation
- Birthday card
- Password-protected secret diary
- Letter modal
- Floating wishes
- Draggable polaroid memory stack
- Cake knife interaction
- Gift reveal modal
- Floating hearts + page navigation
- Responsive phone layout
